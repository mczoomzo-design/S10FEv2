# ระบบรับ-คืนเครื่อง Samsung S10 FE

ระบบจัดการการยืม-คืนแท็บเล็ต Samsung S10 FE สำหรับโรงเรียนเลยอนุกูลวิทยา
สร้างด้วย Google Apps Script + Google Sheets/Drive (หลังบ้าน) และ GitHub Pages (หน้าบ้าน) — ฟรี ไม่ต้องมีเซิร์ฟเวอร์

## ความสามารถ

- **นักเรียนรับเครื่อง** — เลือกชั้น → ห้อง → ชื่อ (ระบุตัวตนด้วยรหัสนักเรียน) แนบภาพถ่าย + สัญญา
- **ครูรับเครื่อง** — พิมพ์ชื่อ + เบอร์โทรเอง (หน้าแยก `teacher.html`)
- **เลขเครื่อง VPN** — พิมพ์เองได้ + มีรายการแนะนำ · บอกสถานะทันที (ว่าง/ถูกยืม/เครื่องใหม่)
- **ถ่ายรูปหรือเลือกไฟล์ก็ได้** ทั้งภาพถ่ายและสัญญา
- **ไม่รับเครื่อง** — แนบเอกสารสละสิทธิ์ 1 หน้า หรือติ๊ก "ส่งทีหลัง" (ผู้ดูแลแนบให้ภายหลัง)
- **คืนเครื่อง** — ครูที่ปรึกษาคืนของนักเรียนผ่านลิงก์ token / ผู้ดูแลคืนของครูในหน้า admin
  - สภาพเครื่อง: ปกติ / ชำรุด (ติ๊กรายการ + แนบภาพ) / สูญหาย (หมายเหตุ)
- **หน้าผู้ดูแล** — สรุปรายห้อง + สรุปครูแยก, ตารางกรอง/ค้นหา, export CSV, สร้างลิงก์ครูที่ปรึกษา, ตั้งค่าระบบ

## โครงสร้างไฟล์

| ไฟล์ | อยู่ที่ | หน้าที่ |
|---|---|---|
| `Code.gs` | Apps Script | หลังบ้าน JSON API ทั้งหมด |
| `config.js` | GitHub | ตั้งค่า API_URL + ฟังก์ชันร่วม (ต้องแก้ URL) |
| `upload.js` | GitHub | วิดเจ็ตอัปโหลดรูป (ใช้ร่วมทุกหน้า) |
| `style.css` | GitHub | ดีไซน์ระบบ |
| `index.html` + `app.js` | GitHub | หน้ารับเครื่องนักเรียน |
| `teacher.html` + `teacher.js` | GitHub | หน้ารับเครื่องครู |
| `return.html` + `return.js` | GitHub | หน้าครูที่ปรึกษาคืนของนักเรียน |
| `admin.html` + `admin.js` | GitHub | หน้าผู้ดูแลระบบ |

## ติดตั้ง

ดู **[คู่มือการติดตั้ง.md](คู่มือการติดตั้ง.md)** — 6 ขั้นตอน ไม่ต้องเขียนโค้ด

โดยสรุป: วาง `Code.gs` ใน Apps Script → รัน `setupSheets` → Deploy เว็บแอป → อัปไฟล์ขึ้น GitHub Pages → แก้ `API_URL` ใน `config.js` → ตั้งค่าในหน้า admin

## สแต็ก

Google Apps Script · Google Sheets · Google Drive · GitHub Pages · Vanilla JS · IBM Plex Sans Thai / Mono

## หมายเหตุ

- ปีการศึกษาไทย (พ.ศ.) ตลอดทั้งระบบ
- อ่าน/เขียนชีตด้วยชื่อหัวคอลัมน์ — ทนต่อการเพิ่มคอลัมน์
- ทุกการเขียนใช้ LockService กันข้อมูลชนกัน
- LINE Notify เลิกให้บริการแล้ว — ระบบไม่ใช้
